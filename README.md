# AI 자격증 교육과정

## 교육과정 소개

AI 자격증 교육과정은 인공지능의 기초 개념을 이해하고, 실습을 통해 AI 활용 역량을 기르며, 관련 자격증 취득을 준비하는 학습 프로젝트입니다. AI를 처음 접하는 학습자도 단계적으로 학습할 수 있도록 이론, 실습, 복습 자료를 함께 구성하는 것을 목표로 합니다.

주요 학습 영역은 다음과 같습니다.

- **인공지능 기초:** AI의 개념, 주요 기술, 활용 사례 이해
- **데이터 이해와 활용:** 데이터 수집, 정리, 분석의 기본 과정 학습
- **머신러닝 기초:** 주요 학습 방법과 모델 평가 개념 이해
- **생성형 AI 활용:** 프롬프트 작성과 학습·업무 활용 실습
- **AI 윤리와 책임:** 개인정보 보호, 저작권, 편향 및 결과 검증 학습
- **자격증 대비:** 학습 내용 정리와 연습문제를 통한 이해도 점검

대상 자격증, 세부 일정, 차시별 학습 내용은 추후 확정하여 안내합니다.

## 프로젝트 목적

이 프로젝트는 AI 학습 자료와 실습 과정을 한곳에 정리하여, 학습자가 기초부터 자격증 준비까지 체계적으로 학습할 수 있도록 돕는 것을 목적으로 합니다.

1. **체계적인 학습 경로 제공:** 기초 개념부터 실습과 평가까지 이어지는 교육과정을 구성합니다.
2. **실무 활용 역량 강화:** AI 도구와 데이터를 직접 다루며 실제 문제에 적용하는 능력을 기릅니다.
3. **자격증 준비 지원:** 대상 자격증의 출제 범위에 맞춰 핵심 개념과 연습문제를 정리합니다.
4. **학습 자료의 지속적인 개선:** 학습 과정에서 발견한 오류와 개선 의견을 반영하여 자료의 품질을 높입니다.

## 진행 현황

현재 프로젝트 초기 기획 단계입니다. 대상 자격증과 학습 목표를 구체화한 뒤, 세부 커리큘럼과 강의 자료, 실습 예제를 순차적으로 추가할 예정입니다.
